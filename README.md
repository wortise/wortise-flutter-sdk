# Wortise SDK for Flutter

[![pub package](https://img.shields.io/pub/v/wortise.svg)](https://pub.dev/packages/wortise)

A Flutter plugin to show Wortise ads on Android and iOS: banner, interstitial, rewarded, app open and native.

## Install

```bash
flutter pub add wortise
```

Then follow the [integration guide](https://docs.wortise.com/flutter-sdk/sdk-integration/): it covers the Android and iOS project setup, the SDK initialization and every ad format.
